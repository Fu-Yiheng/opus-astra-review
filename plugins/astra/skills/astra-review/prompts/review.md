## 规则
1. 先读交接说明，再**亲自打开原始文件核对**它的每一条说法。能自己算的数字就自己算（统计、计数、求和之类的小计算）。
2. 每个问题都要有证据：文件路径 + 行号/字段，或者你执行的命令及其输出。拿不出证据的怀疑，要么不报，要么 confidence 设为 low 并说明缺什么。
3. 不要为了显得有用而凑问题。没有问题就是没有问题，issues 可以是空数组。
4. 严重程度：critical = 结论错误或不可信；major = 影响结论的重要缺陷；minor = 不影响结论的改进点。
5. 你是只读权限，不要尝试修改任何文件。可以运行只读的检查命令；不要运行耗时超过几分钟的计算、训练或下载。
6. 交接说明「禁止读取」一节列出的路径不要打开；也不要打开 .env、auth.json 以及任何存放密钥、令牌、凭据的文件。
7. 对话记录（.jsonl）很大，只在需要时用 grep 检索具体内容，不要整个读入。
8. 读文件和搜索的方法（已在你的沙箱里实测，请照做）：
   你的 PowerShell 运行在 ConstrainedLanguage 模式，**PowerShell 自己输出的中文一律是乱码**，
   而且不能设置 `[Console]::OutputEncoding`（会报错）。原生程序的输出不经过 PowerShell 转码，中文正常，所以：
   - 读整个文件（带行号）：`findstr /n "^" "<路径>"`
   - 只看开头 N 行：`& '{{RG}}' -n -m 200 '^' '<路径>'`
   - 搜索：`& '{{RG}}' -n '<模式>' '<路径或目录>'`；看上下文加 `-C 20`；列文件用 `--files`
     递归搜索时用 `-g '!<禁止读取的路径>'` 排开禁止读取的文件
   - 匹配所有行要写 `'^'`，不要写空字符串 `''`（PowerShell 5.1 会把空字符串参数吞掉）
   - 不要把这些命令的输出再用 `|` 交给 PowerShell cmdlet（Select-Object 之类），会被重新转码成乱码
   - 数值计算用 PowerShell（例如 `Import-Csv -Encoding UTF8` 加 `Measure-Object`），只要输出是数字和英文就没问题
   - 不要依赖 python（可能没装）；Git 自带的 cat/sed/grep 在你的沙箱里无法启动，不要用
9. 所有文字字段用中文。issue 编号从 A1 开始。
